# M032LE: 2xRoller (PID 0x0204)

M0 family, see [m0-family.md](m0-family.md).

- **Descriptor [hw]:** get-feature IDs 0x2d–0x31 and 0x36. There's no 0x32 or 0x34, which fits the module having no LEDs.
- **Reads [hw]:** firmware 01.00.03.01, serial `MHRR02AA41…`, device info (0x31) empty, config (0x36) `10 32 28 c2 5f 94 00 00 00 …`.
- **Scroll [hw]:** report `01 2a 04 00 | 01 02 r1 r2`. Each byte is `00` or `01` for the two directions, `ff` = no change. One report per notch; nothing is reported when a roller is pressed.

## Roller numbering [hw]

The module is mounted horizontally. It can also be mounted vertically.

```
  [r2] [r1]      r2 = left roller, r1 = right roller
```

## Unknown

- Which physical direction `00` is (upstream calls it "up"). hubdeck has an `invert` option per control.
- Whether there are any LEDs
