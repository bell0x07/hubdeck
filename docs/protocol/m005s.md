# M005S: 5xFader (PID 0x0200)

M0 family, see [m0-family.md](m0-family.md). Not connected yet: it needs a swap session, taking out the Knob and the Dial.

- **Positions [up]:** channel 0, event `02 05 s1..s5`, each 0–100.
- **Read positions [up]:** get feature 0x33 returns `33 05 s1..s5`.
- **Lighting [up]:** 5 zones, LED module `0x01`, index 0–4 or `ff` for all.
- **Unknown:** the descriptor, and whether the faders are motorised (assumed not).
