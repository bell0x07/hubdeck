# M4315: 15xKey w/ IPS (PID 0x01FE)

## Descriptor [hw]

| report | direction | size |
| --- | --- | --- |
| input 1 | in | 63 bytes |
| output 2 | out | 319 bytes |
| feature 3 | out | 31 bytes |
| features 0x37–0x3e | get | 31 bytes each |

## Commands

| bytes | meaning | source |
| --- | --- | --- |
| feature `03 3a 01` | software mode on; the module ignores everything else until this is sent | [hw] |
| feature `03 34 <0-100>` | backlight brightness | [hw] |
| feature `03 37 <idx> r g b` | fill one key with a solid colour | [up] |
| feature `03 36 r g b` | fill the whole screen with a solid colour | [up] |
| output `02 36 <chunk u16> <len u16> <key 0-14> <last> <≤312 B JPEG>` | key image: 72×72 baseline JPEG with 4:4:4 subsampling | [hw] |
| output `02 35 …` | full-screen picture (480×272?) | [up] marked work in progress |

## Get features [up]

| id | meaning |
| --- | --- |
| 0x37 / 0x38 / 0x39 | firmware info (MasterHUB uses 0x38) |
| 0x3a | serial number |
| 0x3b | device info. Example: `3b 0b 14 03 05 0f e0 01 10 01 01 48 48` |
| 0x3c | backlight, `3c 01 64` |
| 0x3d | animation info |
| 0x3e | config info |

**[hw]** Our module returns exactly that device info (firmware 02.00.01.00, serial `MHKD15AA43…`). Lined up against the Dial's (see [m131e.md](m131e.md)), it decodes as 3 rows × 5 columns, 15 buttons, a 480×272 screen and 72×72 key images.

## Input [hw]

`01 34 <len u16> 02 0f k1..k15`, where each k is 0 or 1.

## Notes [hw]

- The module sometimes drops off USB on its own and image writes stop being accepted. Reopening the device works.
