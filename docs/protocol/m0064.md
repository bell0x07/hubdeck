# M0064: Base 4x6 (PID 0x01F6)

M0 family, see [m0-family.md](m0-family.md).

- **Descriptor [hw]:** get-feature IDs 0x2d–0x32 and 0x34–0x36.
- **Lighting [hw]:** a single zone, LED module `0x00`, index `0x00`. Static red, white breathing, brightness 5–100 and 250 colour updates/s were all confirmed (see [m0-family.md](m0-family.md)).
- **Reads [hw]:** firmware 02.00.04.00, serial `MHBS01AA46…`, brightness (0x32) `01 64`, mode (0x34) `01 09` = rainbow, 0x35 returns `00` (empty).
- **Input [hw]:** channel 1 sends a heartbeat `01 2b 01 00 01` every ~0.5 s. Upstream documented its payload as `00`; ours sends `01`. No user controls.
- **Unknown:** how many LEDs there are and where, and whether the Base reports which modules are attached (its config dump contained a Dial serial number).
